# Enhanced Distanciador - Consumer Density Analysis

## 🚀 Overview

The **Enhanced Distanciador** is an advanced geographic proximity analysis tool that combines the original shopping mall proximity calculator with Shopify customer data processing capabilities. It provides comprehensive consumer density analysis, high-value customer clustering, and business intelligence insights.

## ✨ New Features

### 🛒 Shopify Integration
- **Automatic data processing** from Shopify customer exports
- **Revenue analysis** by geographic location
- **Customer segmentation** based on spending patterns
- **Order frequency analysis** by region

### 📊 Consumer Density Analysis
- **Geographic density mapping** by CEP (postal code)
- **City-level analysis** with customer concentration metrics
- **Revenue density visualization** for business intelligence
- **High-value customer clusters** near shopping malls

### 🎯 Business Intelligence
- **Shopping mall performance analysis** by customer proximity
- **Revenue optimization insights** based on geographic data
- **Customer acquisition opportunities** identification
- **Market expansion recommendations**

## 🚀 Quick Start

### Basic Usage

```python
from enhanced_distanciador import EnhancedDistanciador

# Initialize the system
distanciador = EnhancedDistanciador()

# Process Shopify data and generate complete report
summary = distanciador.gerar_relatorio_completo('customers_export.csv')
print(f"Total customers analyzed: {summary['total_customers']}")
```

### Advanced Usage

```python
# Process Shopify data
df_shopify = distanciador.processar_shopify_data('customers_export.csv')

# Analyze consumer density
df_density = distanciador.analisar_densidade_consumidores(df_shopify)

# Identify high-value clusters
df_clusters = distanciador.identificar_clusters_altos_valores(
    df_shopify, 
    min_revenue=1000, 
    max_distance=15
)

# City-level analysis
df_city_density = distanciador.analisar_densidade_por_cidade(df_shopify)
```

## 📊 Analysis Capabilities

### 1. Consumer Density Analysis
- **CEP-level density**: Customer count per postal code
- **Revenue density**: Total spending per geographic area
- **Order density**: Purchase frequency by location
- **Density categories**: Automatic classification (Baixa, Média, Alta, etc.)

### 2. Shopping Mall Performance
- **Customer proximity analysis**: How many customers are near each mall
- **Revenue attribution**: Revenue generated by customers near each mall
- **Distance optimization**: Optimal mall locations based on customer distribution

### 3. High-Value Customer Clusters
- **Revenue thresholds**: Identify customers spending above minimum
- **Distance filtering**: Focus on customers within reasonable distance
- **Cluster analysis**: Group high-value customers by shopping mall proximity

### 4. City-Level Insights
- **Customer concentration**: Which cities have the most customers
- **Revenue per city**: Total and average revenue by city
- **Market penetration**: Customer density relative to city size

## 📈 Output Files

The system generates several output files with timestamps:

- `shopify_processed_[timestamp].csv` - Processed Shopify data with coordinates
- `consumer_density_[timestamp].csv` - Density analysis by CEP
- `city_density_[timestamp].csv` - City-level density analysis
- `high_value_clusters_[timestamp].csv` - High-value customer clusters
- `analysis_summary_[timestamp].json` - Complete analysis summary
