# GeoCommerce - E-commerce Geographic Analysis Platform

## 🚀 Overview

**GeoCommerce** is an advanced geographic analysis platform designed specifically for e-commerce businesses. It provides comprehensive customer density mapping, shopping mall proximity analysis, and business intelligence insights to optimize your geographic strategy.

## ✨ Key Features

### 🛒 **E-commerce Focused Analysis**
- **Shopify Integration**: Direct processing of Shopify customer exports
- **Revenue Density Mapping**: Visualize revenue concentration by geographic areas
- **Customer Segmentation**: Analyze customer behavior by location and spending
- **Order Frequency Analysis**: Understand purchase patterns by region

### 📊 **Geographic Intelligence**
- **CEP-level Density**: Customer count and revenue per postal code
- **City-level Analysis**: Market concentration and penetration metrics
- **Shopping Mall Proximity**: Distance analysis to physical retail locations
- **High-value Customer Clusters**: Identify premium customer geographic concentrations

### 🎯 **Business Intelligence**
- **Market Expansion Opportunities**: Identify underserved areas with high potential
- **Revenue Optimization**: Geographic insights for pricing and marketing strategies
- **Customer Acquisition**: Location-based targeting recommendations
- **Competitive Analysis**: Geographic market share and territory optimization

## 🚀 Quick Start

### **Basic Usage**
```python
from geocommerce_core import GeoCommerce

# Initialize the platform
geocommerce = GeoCommerce()

# Generate comprehensive analysis
summary = geocommerce.generate_comprehensive_report('customers_export.csv')
print(f"Total customers analyzed: {summary['total_customers']}")
```

### **Advanced Usage**
```python
# Process Shopify data
df_shopify = geocommerce.process_shopify_data('customers_export.csv')

# Analyze customer density
df_density = geocommerce.analyze_customer_density(df_shopify)

# Identify high-value clusters
df_clusters = geocommerce.identify_high_value_clusters(
    df_shopify, 
    min_revenue=1000, 
    max_distance=15
)

# City-level analysis
df_city_density = geocommerce.analyze_city_density(df_shopify)
```

## 📈 Output Files

The system generates timestamped output files:

- `shopify_processed_[timestamp].csv` - Processed customer data with coordinates
- `customer_density_[timestamp].csv` - Density analysis by CEP
- `city_density_[timestamp].csv` - City-level density analysis
- `high_value_clusters_[timestamp].csv` - High-value customer clusters
- `geocommerce_summary_[timestamp].json` - Complete analysis summary

### **Custom Configuration**
```python

    'My Mall': (-23.564738, -46.668939),
    'My Center': (-22.956909, -43.176186)

    'high_value_max_distance': 12

geocommerce = GeoCommerce(custom_config)
```
