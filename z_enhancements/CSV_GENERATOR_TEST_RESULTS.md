## 🔧 CSV Structure

The generated CSV follows Shopify's blog import format with these columns:

| Column | Description | Example |
|--------|-------------|---------|
| `Command` | Import action | `MERGE` |
| `Title` | Post title | `transforme seu banho em autocuidado com produtos capilares` |
| `Author` | Post author | `GE Beauty Redação` |
| `Body HTML` | Full HTML content | ````html<h2>Transforme o Banho...</h2>...` |
| `Summary HTML` | Post excerpt | `Descubra como transformar sua rotina...` |
| `Tags` | Post tags | (empty) |
| `Published` | Publication status | `VERDADEIRO` |
| `Blog: Handle` | Blog identifier | `gebeauty-blog` |
| `Blog: Title` | Blog name | `GE Beauty Blog` |
| `Metafield: title_tag [string]` | SEO title | Same as Title |
| `Metafield: description_tag [string]` | SEO description | Meta description from metafields |
| `Metafield: custom.produto [list.product_reference]` | Related products | Product slugs |
