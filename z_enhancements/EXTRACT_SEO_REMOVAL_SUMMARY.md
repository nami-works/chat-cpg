### **Before (with extract_seo):**

## Fallback System

The system includes a robust fallback mechanism:
- **Primary**: Uses enhanced keywords data when available
- **Fallback**: Generates basic semantic fields without external dependencies
- **Graceful degradation**: System continues to function even without enhanced data
